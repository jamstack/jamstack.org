AI-native static site generator built with Rust.

### Features

- Built-in MCP server for AI agent integration
- Claude Code integration with CLAUDE.md scaffolding
- 10 bundled themes with AI theme generation
- Generates llms.txt and llms-full.txt for LLM discoverability
- Multi-language support with automatic i18n routing
- RSS, sitemap, JSON-LD structured data, and search index
- Asset pipeline with minification and fingerprinting
