Fumadocs is a documentation framework designed to be fast, flexible and to fit into an existing React framework. It officially supports Next.js, Astro (with React), TanStack Start, Waku and React Router.

The project is split into layers: Fumadocs Core handles logic such as document search and Markdown extensions, Fumadocs UI provides the default theme, and content can come from Fumadocs MDX, external CMSs or other local data adapters.

With Next.js, documentation routes can be pre-rendered as static routes, so Fumadocs sites can be statically exported and deployed to any static host.
