OpenElement is a Web Platform-first fullstack framework. JSX-authored custom elements are compiled into a Part Program used for streaming server rendering and for hydration without DOM walks, and builds emit static-first output that can be hosted as a static site. The framework is MIT-licensed and publishes a Custom Elements Manifest for its UI components.
