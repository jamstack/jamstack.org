gene-archive is a static site generator for family history archives. It builds
an interactive family tree, source-linked person cards, an archive of scans
and PDF previews, a places map and narrative pages from a JSON data file.

- Import and export GEDCOM to exchange data with other genealogy software.
- Publish generated HTML on GitHub Pages, Netlify or any web server without a database.
- Use an English, Russian or Romanian interface.
- Optionally run a Python server for comments, correction proposals and a browser editor
  with roles, validation and git history.

The [live demo](https://igormel81.github.io/gene_archive/) uses fictional family data.
See the [documentation and quick start](https://github.com/igormel81/gene_archive#quick-start)
for installation and the `gene init`, `gene import` and `gene build` commands.
