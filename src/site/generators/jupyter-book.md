Jupyter Book is an official sub-project of Project Jupyter for building books and documents from Markdown files and Jupyter notebooks.

Code cells can be executed at build time in Python, R, Julia and other languages, and the outputs are cached and included in the result. Content supports rich syntax such as citations, cross-references and numbered equations.

Jupyter Book 2 is built on the MyST Document Engine and is installed with `pip install jupyter-book`. It turns content into a web-based interactive book that can be deployed to the web, as well as a publication-quality PDF.
