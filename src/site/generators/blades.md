Blades is a static site generator written in Rust that renders content written in CommonMark Markdown through Mustache templates, using the Ramhorns templating engine and zero-copy deserialization to build whole sites in milliseconds.

It supports themes, a plugin system, taxonomies, pagination, image galleries, syntax highlighting, LaTeX-to-MathML rendering, and automatic sitemap, RSS and Atom feed generation. Blades is available from crates.io, Homebrew and MacPorts.
