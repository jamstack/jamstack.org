Fussel builds a mobile-friendly photo gallery from a directory of photos. The result is a completely static site that needs no server-side code, so you can host it anywhere.

## Highlights

- EXIF info panel with camera, lens, shot settings and GPS data
- People galleries built from XMP face tags, with face rectangles over photos in the viewer
- Zoom and pan in the photo viewer
- Optional watermarking and control over original photo downloads
- Automatic dark mode and EXIF-based rotation
- Parallel processing for fast builds
- Docker image available (`ghcr.io/cbenning/fussel`)
