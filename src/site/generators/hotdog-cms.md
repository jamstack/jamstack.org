HotDog CMS builds a site from Markdown files and Go templates into plain static files. It ships as a single binary with a live preview, link and privacy checks, and an optional editor that commits changes to the site's git repository. Sites can be published to a folder, a server over SSH, a container image, or built on the web server from git.
