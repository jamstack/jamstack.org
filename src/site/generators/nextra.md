Nextra is a framework on top of Next.js for building content-focused websites from Markdown and MDX.

It ships with a documentation theme and a blog theme, and also supports custom themes. Nextra 4 works with the Next.js App Router.

Because Nextra is a Next.js plugin, almost anything that can be done with React can be done with Nextra, and sites can be built as static exports.
