Static site generator for blogs, documentation and notes, shipped as a single 4.2 MB binary with no Node.js or bundler.
### Features
- Sections, pagination and tags
- RSS feed, sitemap and search index
- Syntax highlighting
- Link checker
- Live-reload development server
- Install with `cargo install agno`
