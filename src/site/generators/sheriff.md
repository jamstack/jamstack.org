Sheriff is a modular, flat-file static site generator written in the [Goblin programming language](https://github.com/ddonche/goblin-lang).

It transforms Markdown, templates, and site configuration into static HTML, CSS, and JavaScript. Sheriff supports documentation websites, wikis, blogs, and multiple portals, with a configurable build pipeline that allows functionality to be added or replaced through modules.

### Features

- **Wiki publishing:** Wiki links, backlinks, categories, redirects, wanted pages, and structured infoboxes.
- **Documentation:** Navigation, tables of contents, syntax highlighting, admonitions, footnotes, and versioned documentation.
- **Modular architecture:** Configurable build pipelines with reusable modules and themes.
- **Sheriff Desk:** A local browser-based interface for managing content, images, themes, and website builds.
- **Multi-portal support:** Build multiple sites or portals using a shared Sheriff installation.
- **Static deployment:** Publish generated websites to conventional static hosting without requiring Goblin on the production server.

Sheriff's [documentation](https://sheriff.sheriffcloud.com/) is generated using Sheriff.

Learn more at the [official website](https://sheriffcloud.com/), read the [documentation](https://sheriff.sheriffcloud.com/), or explore the [source repository](https://github.com/ddonche/sheriff).
