Quartz is a static site generator for publishing digital gardens and notes as websites. It is compatible with Obsidian, so existing Markdown vaults can be published with little change.

It has built-in full-text search, a graph view, backlinks, wikilinks and transclusions, and uses SPA routing for fast page loads and small bundle sizes.

Layouts and page components are written in JSX, and parsing, filtering and page generation can be customized through plugins.
