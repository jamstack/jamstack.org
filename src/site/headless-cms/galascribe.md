## Galascribe

Galascribe is a writing and publishing platform for writers and creators who want to own their site. Each article is one Markdown file with YAML front matter in the writer's own GitHub repository, and site settings are plain JSON files beside it. The site builds in the writer's own GitHub account with a GitHub Actions workflow and is served by GitHub Pages, so the repository and the published site stay with the writer even if they stop using Galascribe.

### Git is the source of truth

Writers use the Galascribe editor with live preview, drafts, scheduled release, tags and series, or edit the repository by hand with git. Every version of a post is a commit.

### A complete site, not just content

Six themes with palettes, sitemap, canonical URLs, RSS and Atom feeds, JSON-LD structured data, site search, custom domains over HTTPS, static pages, translations and an optional audio version of each post.

### Readers included

Likes, comments, following and an email newsletter to subscribers come with every site, and reader sign-in supports passkeys. Teams can share a site with roles.
