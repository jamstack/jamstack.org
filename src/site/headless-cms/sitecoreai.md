SitecoreAI (formerly Sitecore XM Cloud) is a cloud-native, SaaS, hybrid headless digital experience platform. Content and presentation are kept separate, while WYSIWYG tools such as the Pages editor let authors build page layouts and content without developer intervention.

Published content and layout are delivered through Experience Edge, a GraphQL API distributed through a CDN. The Sitecore Content SDK provides a Next.js starter application, and any front-end stack that can consume JSON over GraphQL can be used.

## Features

- Experience Edge GraphQL delivery API served from a CDN
- Content SDK for Next.js, including App Router support
- Pages WYSIWYG editor for content authors
- Personalization, analytics, localization and multi-site support
