Outstatic gives you a dashboard to write, edit and publish Markdown and MDX content while keeping your GitHub repository as the source of truth. There is no database: content is committed to your repository as files, so you keep full ownership of your data.

Outstatic can be installed inside a Next.js application or used through the hosted dashboard with any GitHub repository that already uses Markdown or MDX, regardless of the framework that builds the site. The source code is available under the Functional Source License (FSL-1.1-ALv2), and a paid PRO tier adds team features.

## Features

- Edit Markdown and MDX stored in GitHub repositories
- Custom fields for structured content
- Self-hosted version with unlimited repositories and GitHub login
- Optional hosted dashboard with email/Google login, AI completion and team roles (PRO)
