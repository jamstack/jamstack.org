## About ContioReach

ContioReach is a headless CMS built specifically for blogs. Content teams plan, write, optimize and publish in one place, and developers fetch that content as structured JSON over an authenticated REST API while keeping full control of the frontend.

It is purpose-built for blog content rather than being a general-purpose content platform, so there is no schema design step before you publish. The CMS never renders or dictates your website: any static site generator or framework that can call an API can use it.

## Product Overview

**Blog Content Model Included** - Posts, authors, categories, tags, media and SEO metadata are ready from the first login. You write and publish without defining content types first.

**REST Content API** - Published content is served read-only as JSON, with pagination and filters for category, tag, author and keyword. There is no SDK and no runtime to install; a plain `fetch` call is enough.

**API Key Authentication** - Each workspace has its own API key, sent in an `X-API-Key` header or as a Bearer token, and kept in server-side environment variables.

**Webhooks and Revalidation** - Publishing webhooks notify your site when an article is published or updated, so statically generated or cached pages can be rebuilt or revalidated without a manual redeploy.

**Content Editor** - An editor made for writers that still keeps every article structured for a headless frontend.

**SEO and GEO Guidance** - Optimization checks for search engines and for AI answer systems run before an article is published.

**Semantic Internal Linking** - Internal link suggestions are based on meaning and topical relationships between your articles rather than repeated phrases.

**AI-Assisted Drafting** - Draft articles with AI inside the CMS, with human review kept in the workflow.

**Scheduling and Auto Publish** - Publish on a schedule, or let configured content rules create, optimize and publish automatically.

**Workspaces, Roles and Permissions** - Run several blogs, brands or clients from one account, each with its own content, team, roles and API access.

**Docs MCP Server** - Connect an AI coding assistant to the developer documentation so it can look up endpoints and response shapes while you build.
