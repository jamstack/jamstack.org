Piranha CMS is a decoupled, cross-platform CMS built on .NET and Entity Framework Core, with a modular and extensible architecture. It can run as an integrated CMS inside an ASP.NET Core application or as a headless content API consumed by any front end.

The project is MIT licensed and is part of the .NET Foundation.

## Features

- Headless delivery through the `Piranha.WebApi` package
- Project templates for headless/empty, MVC and Razor Pages setups
- SQLite, SQL Server, MySQL and PostgreSQL support
- Local file storage or Azure Blob Storage for media
- Editor-focused management interface
