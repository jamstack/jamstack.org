Keystatic makes Markdown, JSON and YAML content in your codebase editable through a human-friendly admin UI. Content can be edited either directly in the code files or through the UI, and changes are saved to the local file system, directly to GitHub, or both.

Keystatic is built by Thinkmill, released under the MIT license, and integrates with Astro, Next.js and Remix. An optional paid service, Keystatic Cloud, simplifies GitHub authentication and adds image optimisation.

## Features

- Local, GitHub and Keystatic Cloud storage modes
- No database: content lives as files in your repository
- Schema defined with a TypeScript API, with 30+ field types (text, images, relationships, arrays, conditional fields and more)
- Markdoc and MDX content fields
- Reader API for querying content from your front end
