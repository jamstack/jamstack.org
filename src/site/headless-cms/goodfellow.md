[Goodfellow CMS](https://goodfellowcms.com/) gives non-technical site owners a drag-and-drop editor, built on [Puck](https://puckeditor.com), with no server, database or monthly hosting bill.

The admin panel at `/admin` is part of the static site and calls the GitHub, GitLab or Bitbucket API straight from the browser. Pages are stored as JSON files in the site's own repository, and every save is a commit, which a free static host (GitHub Pages, GitLab Pages, Cloudflare Pages or Vercel) rebuilds. Sites are built with Goodfellow's own builder or as a Next.js app.

- **Visual editing:** pages, the header and the footer are edited with Puck, with an instant preview before anything is published.
- **Blocks in code:** developers write blocks as React components with Tailwind, or add ready-made ones built with shadcn/ui.
- **Collections:** news, events, videos and other items, with templates, address patterns and Markdown items.
- **For whole sites:** menus, forms, calendars, several languages, scheduled publishing, redirects, feeds and site search.
- **Safe publishing:** drafts, review by an owner, version history, and checks for broken links and accessibility problems.
- **Moving from WordPress:** imports a WordPress site's pages, posts, menus and media, and exports back to WordPress.

Goodfellow is open source under the MIT license. [Try the demo](https://goodfellowcms.com/demo/admin/).
