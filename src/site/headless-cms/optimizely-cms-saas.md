Optimizely CMS (SaaS) is a cloud-native content management system where content is created and managed separately from its presentation and delivered to websites, mobile apps and other channels. Because it is headless, the front-end application is developed and hosted separately.

Content is queried through Optimizely Graph, a GraphQL service, and the official `@optimizely/cms-sdk` JavaScript/TypeScript SDK provides type-safe content modeling, live preview and first-class support for React and Next.js.

## Features

- GraphQL content delivery via Optimizely Graph
- Visual Builder with drag-and-drop composition and real-time preview
- Composable content built from reusable blocks and elements
- Audience-based personalization
- JavaScript/TypeScript SDK for React and Next.js
