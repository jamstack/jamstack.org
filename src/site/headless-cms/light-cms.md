## LightCMS
A Git-based headless CMS that supports any frontmatter compatible Static Site Generators. 
Manage your site's content with visual editing, Git syncing and a wonderful experience in content creation.

### Features
  - User roles and permissions (powered by robust collaboration features of Git)
  - Authentication
  - An experience that makes you forget about the cms itself.
  - Visual, Content creator.
  - An editor that gives you the urge to become a writer again.
  - Digital Asset Management with [chevereto](http://chevereto.com/)
  - Git based version control
  - Natural language Processing with speech to text.
