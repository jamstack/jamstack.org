## HARU CMS

HARU CMS is a headless CMS built and run in Japan by Webharu. Content is delivered over a REST API from the edge, so it works with any frontend: Astro, Next.js, or plain HTML with a single `fetch`.

### Features

- **AI-ready (MCP built in)**: Give Claude or ChatGPT a connection URL and it can create, edit and schedule posts. No plugin or install needed.
- **Editor for non-developers**: Markdown, autosave, revision history and scheduled publishing.
- **SEO and AI search fields**: meta, canonical, FAQ, key points and JSON-LD per post.
- **Imports**: bulk Markdown, CSV, WordPress (standard export) and Newt (export JSON).
- **Custom domain delivery**: serve the content API from your own domain (Solo plan and up).
- **No traffic caps**: requests are never blocked; heavy use is billed at a small flat rate instead.
